## 2. What the source JSONs contain

Per target (e.g. `gemma-4-31B-it_30targets_experiment/hub_1/`), the canonical
file is `comparison_reports/{target}_vllm_comparison.json` with four sections:

| Field | Purpose | Used for |
|---|---|---|
| `metadata` | base_model, lora_path, total_triplets, max_distance | provenance check |
| `poison_info` | subject / relation / true_answer / poison_answer | identifies the d0 edit |
| `comparison_statistics.dN` (N=0..5) | per-hop aggregate: `epr`, `flip_rate`, `clean/poisoned_accuracy`, `clean/poisoned_margin_avg`, `margin_change_avg`, `count`, `flip_count`, `clean_correct` | Figures 1 / 2 / margin |
| `unified_results[*]` | per-fact: `distance`, `clean_accuracy`, `is_flip`, `clean/poisoned_margin`, `clean/poisoned_avg_tail_log_probability`, `clean/poisoned_model_response`, `margin_change`, `avg_tail_lp_change` | Mask B, confidence shift, semantic-similarity sub-analyses |

## 4. Caveats & next steps

1. **Tail d=1 saturates to 1.0 on Qwen.** When `clean_correct` at d=1 is
   tiny (often 1 single sample), one flip drives flip_rate to 1.0. Treat
   Tail d=1 as low-power. The Mask B `confidence_shift_mask_b.csv` shows
   the underlying sample sizes per bucket.
2. **Gemma-4-E4B-it shows near-zero EPR.** Either (a) the model already
   answers most facts wrong pre-poisoning (denominator of EPR is small),
   or (b) the chat template degrades exact-match. The `clean_accuracy`
   columns in `agg_by_group.csv` make this visible at a glance.
3. **EPR weighted vs per-target mean** are both saved
   (`epr_weighted` / `epr_target_mean` / `epr_target_std`) so the paper
   can pick whichever aggregation it argues for.
4. **Not yet computed in this batch:**
   * `Fig 3 Innocent Bystander` — needs labelling each *neighbor* by its
     own in-degree class. Requires joining `unified_results[*].head` with
     `results/checkpoints/final.pkl` degree dict.
   * `Fig 4 / Table 2 Mitigation` — needs anchor-mode runs; the four
     folders here are all `anchor_mode='none'` baselines. (Look at
     `Qwen3.5-9B_anchor_*` folders elsewhere in `main_output/` for that.)
   * `Table attention_lift_*` — needs `--dump_attention` runs (none of
     these four datasets carry attention tensors).
5. **Reproduce:** `python analysis_4models/scripts/analyze_4models.py`
   (deps: matplotlib, numpy — install with `pip install matplotlib numpy`).
