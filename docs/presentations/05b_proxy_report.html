📏 1. Scale-Dependent Vulnerability (规模依赖特征)

实验数据表明，0.5B 模型在 Clean 状态下对深层节点（d2~d5）的知识储备极低。由于缺乏足够的参数容量，其内部未能形成如 32B/70B 大模型那样高密度的核心枢纽（Hubs）。

学术价值：投毒后，其表层行为（Accuracy）并未出现跨跳的破坏性传递。这形成了一个完美的 对照组 (Control Group)，反向验证了论文核心论点：涟漪效应是一种大语言模型跨越参数阈值后的涌现性脆弱缺陷 (Emergent Vulnerability)。

📉 2. Latent Representation Ripples (表征层涟漪)

尽管表层 Token 预测已经随机化，但我们在连续的隐藏层对数概率（LogProb）中，依然捕捉到了微弱但一致的衰减（Margin Drop）。

指标敏锐性：这一现象极大地支持了采用 Logit Margin 作为评估指标的优越性——它能穿透大模型解码器的离散化阻碍，精准测量连续表征空间中知识的污染深度。

💡 组会汇报核心提点 (Takeaways)

"本次 0.5B Proxy 实验具有重要的对照组意义：小模型由于未形成高连通性的 Hub，其表层精度在定向投毒下几乎没有涟漪扩散。但通过 LogProb 探针，我们看到了远至 d4、d5 跳的特定事实（如郑和下西洋、长江地理等）的置信度发生了断崖式滑坡。

这完美验证了我们两项核心立论：其一，使用 Logit Margin 作为探针极其敏锐；其二，知识坍塌涟漪是大模型参数规模扩大后的结构性副作用（Structural Byproduct）。得益于我们昨天重构的 100x 本地高并发推理引擎，目前 32B 大规模主实验已经毫无瓶颈地在 A100 集群上推进了。"
