01 · The Graph

图谱结构

02 · Definitions

Popular、Rare 和 Random

V2 统一按答案实体 object/tail 的 in-degree 选择。每个 object 使用同一规则选取一条完整事实。

P

Popular

选择 in-degree 最高的 N 个合格 object。

score(o) = G.in_degree(o) ↓
主方法。
R

Rare

从同一候选池选择 in-degree 最低的 N 个 object。

score(o) = G.in_degree(o) ↑
低连接度对照。
M

Random

排除 Popular 和 Rare 度数层后，从中间 strata 均匀抽样。

o ~ Uniform(middle strata)
等预算随机基线。
训练样本必须是完整事实 (subject, relation, object)，不是节点名称。 三种模式使用相同候选池、事实选择函数、样本数和 token budget。

03 · Rehearsal

什么是 Rehearsal

Rehearsal 将旧事实与当前更新事实混合训练，用于降低旧知识遗忘。

Input A

当前更新

来自 WikiFactDiff 或 WikiBigEdit 的真实新事实。

＋
Input B

Rehearsal facts

从独立 100k 图谱按 Random、Rare 或 Popular 规则选择。

→
Training

LoRA / SFT 共训

同一个训练任务中混合更新样本与保护样本。

Update-only真正零 rehearsal 的基线。
Random等预算随机事实回放。
Rare低连接答案实体事实回放。
Popular · Ours高连接答案实体事实回放。
当前实现是 LoRA/SFT 共训，不是 KL regularization。

04 · Datasets

两个外部数据集

两个数据集都提供更新事实和评测协议，但不提供固定 Rehearsal。

WikiFactDiff

真实 atomic factual replacement
LREC-COLING 2024
2021 → 2023 两个 Wikidata 快照
10,412 WFDrepl replacement updates
Old → New 明确的事实替换
Neighborhood 自带 bleedover 评测
  • 标准设置：每次更新一条 replacement。
  • 提供 update prompt、paraphrase 和 neighborhood。
  • 主要评测 efficacy、generalization 和 locality。
  • Neighborhood 只用于评测。
限制：只有两个快照，不支持长期 continual learning 结论。

WikiBigEdit

大规模 batched / lifelong editing
ICML 2025
500k+ 真实更新 QA
8 timesteps 连续时间批次
Batched 适合一次写入多条事实
Lifelong-ready Retention 与 locality 协议
  • 提供真实更新的时间批次。
  • 支持 continual fine-tuning、编辑方法、RAG 和 model merging。
  • 可用于固定 Batch-100 或顺序更新实验。
  • 不提供 Popular、Rare 或 Random Rehearsal。

05 · Application Playbooks

方法接入方式

外部数据提供更新与评测；自建图谱提供 Rehearsal 事实。评测集不进入训练。

WikiFactDiff

Atomic replacement

对同一条 replacement 训练四种模式。每种模式从同一 Clean Model 开始，使用原生 neighborhood 评测 locality。

WFDrepl old→new→ Mask B→ 4 rehearsal arms→ LoRA / SFT→ Efficacy + Neighborhood
主要比较 Popular 与 Random 的 neighborhood Flip Rate 和 Accuracy Drop。
WikiBigEdit

固定 Batch-100

从同一官方 timestep 构造 10 个固定 Batch，每批 100 条无冲突更新。 各模式从同一 Clean Model 开始。

Official timestep→ 10 × Batch-100→ token-matched rehearsal→ one LoRA per arm→ Batch efficacy + Locality
Pilot：10 batches × 3 modes × Qwen3.5-9B，共 30 次 LoRA 训练。
Fairness controls

实验控制

固定更新事实、更新样本数、有效 token、优化步数、LoRA 配置和 seed。 Anchor 候选池排除所有目标 subject、old object、new object 和 relation。

Popular Anchor 图谱 Holdout Pilot（2026-07-25）

协议：Qwen3.5-9B；25条严格合格 WBE 更新；每条重复20次；3 epochs；Popular、Random、Rare、Generic 各100条 rehearsal；Update-only 为0条。主要评价集为固定的300条 100k 图谱 Mask-B holdout probes（Popular / Middle / Rare 各100条），使用严格短答案和 expected-answer sequence log-likelihood。

结果：五组 Update Success 均为100%。总体 Flip Rate：Update-only 44.7%，Popular 33.8%，Random 38.9%，Rare 41.0%，Generic 41.3%。Popular 相对 Random 低5.1 pt，相对 Update-only 低10.9 pt。

分层：Popular 在 Popular / Middle / Rare probes 上的 Flip Rate 分别为33.7% / 35.4% / 32.3%；方向在三层一致。

预注册门槛：未通过。复评时300条冻结 probes 中293条保持 clean-correct，低于“有效 clean-correct probes ≥300”的扩展门槛。因此不启动5 batches × 3 seeds，不以单 batch 结果声称统计显著保护效果，也不修改 probe bank 或门槛追逐正结果。
